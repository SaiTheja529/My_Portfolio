# Contributing

Thanks for taking a look at my portfolio! This is a personal site, so I'm not looking for large
feature PRs — but suggestions, bug reports and small fixes are very welcome.

## Ideas, suggestions & collaboration

I'm open to suggestions, project ideas and any sort of collaboration.

- Open an [issue](https://github.com/SaiTheja529/My_Portfolio/issues/new) to share an idea or report a bug.
- Or email me at <saithejapapisetty@gmail.com>.

## Reporting a bug

Please include:

- What you expected to happen, and what actually happened
- Your browser, OS and screen size (many effects are 3D / WebGL)
- Steps to reproduce, and a screenshot if it's visual

## Security issues

Please do **not** report security issues in a public issue — see [SECURITY.md](SECURITY.md).

## Sending a pull request

1. Fork the repo and create a branch from `main`.
2. Install and run it: `pnpm install` then `pnpm dev`.
3. Keep changes small and focused, and make sure `pnpm lint` and `pnpm build` pass.
4. Describe what changed and why in the PR.

By participating you agree to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
