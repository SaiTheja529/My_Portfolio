# Security Policy

## Supported Versions

This project is maintained on the default branch. Please use the latest commit when reporting issues.

## Reporting a Vulnerability

Report security vulnerabilities privately to <saithejapapisetty@gmail.com>.
Please do not open a public GitHub issue for security reports.

Reports will be reviewed as soon as possible. If a report is accepted, I will work on a fix.
If it is declined, I will explain why.
